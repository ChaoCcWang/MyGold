# 我的金啊 · My Gold

macOS 菜单栏行情工具：黄金、股票（A股/港股/美股）、基金实时涨跌一览。

> ⚠️ **本项目仅作个人学习与测试用途，禁止任何商用。**
> 数据均来自第三方公开接口，非官方授权，准确性与时效性不作保证；使用产生的一切后果自负。

---

## 功能

### 状态栏
- 点击图标展开下拉面板：自选前 5 大字报价 +「详细信息」入口

### 行情详情窗口
- 独立窗口展示全部自选：开市状态、种类、现价、涨跌幅、更新时间
- 支持**图钉置顶**：钉在桌面最上方，盯盘不被遮挡

### 自选管理
- 搜索添加：支持 **名称 / 拼音 / 代码**（如「美团」「gzmt」「110022」）
- 品类：黄金 / 基金 / 股票（A股、指数、港股、美股）
- 拖动排序，前 5 项同步到下拉面板

### 其他
- 刷新频率三档：高（15 秒）/ 中（1 分钟）/ 低（5 分钟）；休市自动降为 2 分钟
- 交易时段按市场独立判断：金交所（含夜盘）、A股、港股；开市状态逐标的显示
- 开机自启（登录项）
- 首次安装弹引导，指引状态栏位置
- 通过 GitHub Release 检测/安装更新

## 数据来源

| 数据 | 来源 | 说明 |
|---|---|---|
| 黄金 | 招商银行 `m.cmbchina.com` | Au99.99 等品种现价/昨收；休市间隙自动回退昨收 |
| 股票/指数 | 腾讯 `qt.gtimg.cn`（主）+ 新浪 `hq.sinajs.cn`（备） | A股、港股、美股实时行情，GBK 编码 |
| 基金净值 | 东方财富 `fundmobapi.eastmoney.com` | 官方净值，T+1 更新 |
| 基金估值 | 新浪财经 | 盘中实时估算，界面标注「估值」 |
| 搜索 | 东方财富 FundSearchAPI / SmartBox | 基金与全品类证券搜索 |

以上均为**非官方公开接口**，仅供学习研究，请控制请求频率。接口随时可能变更或失效。

## 安装与更新

1. 从 [Releases](../../releases) 下载最新 `GoldPrice-x.x.x.pkg`
2. 双击安装（未签名包需在「系统设置 → 隐私与安全性」中点「仍要打开」）
3. 安装完成自动启动，看屏幕右上角状态栏

App 内「关于 → 检测更新」可检查并安装新版本。

## 卸载

```bash
sudo rm -rf /Applications/GoldPrice.app
rm -rf ~/Library/Application\ Support/GoldPriceApp
```

## 系统要求
